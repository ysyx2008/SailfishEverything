# 产品 SPEC

> Last verified: 2026-09-02

## 职责

在 Mac 上按文件名找文件：常驻、边敲边出、结果铺成一张大表。这是独立软件，不是旗鱼里的一个功能。

## 设计目标

### 要解决什么

从 Windows 用惯了 Everything，换到 Mac 之后，找不到同等手感的东西。

日常用法很明确：记得文件名里有几个字，想立刻摊开所有对得上的文件，靠路径自己认。不是按正文找，也不要系统搜索那种「猜你想干什么」。

痛点是两件叠在一起：

1. **搜的范围不对**：系统搜索把正文、邮件、网页、词典跟文件名混在一起排，名字完全对上的反而被挤下去。
2. **看的方式不对**：结果窗只有一条缝，五六条就没了。Everything 是一张大表，路径一眼能辨。

系统搜索没有「只搜文件名」的总开关。偶尔改一次条件能救急，但那不是肌肉记忆。

### 是什么 / 不是什么

**是**：Mac 上的 Everything。只认文件名和路径。常驻、边敲边出、结果铺满。

**不是**：启动器、全文搜索、系统搜索套皮、旗鱼的一个功能。

对手不是系统自带搜索，是「有没有人已经把这口饭吃成习惯」。Windows 上那家也没出过 Mac 版。

### 边敲边出不能让

每多一个字，列表立刻变窄。回车把「边想边找」变成「先猜完再问」，手感断了。

没这个，就不必做。仿制品最常见的走样是皮像、手感不像：必须按回车才搜。

### 看的方式是一张大表

结果要铺开，名称和路径同时看得见，自己靠路径认。不要启动器那种只露几条的缝。

### 对手和手感

后来装过同定位的开源软件试过：功能和界面已经够用，但每敲一次搜索，屏幕会闪一下。用久了比少一个按钮更难受。Everything 的表是钉在那儿的，字变了行在收，背景不动。

还做的理由，首先守这条手感：列表要稳，不能每敲一字闪一下。功能对齐不难，手感就卡在这种地方。

另有一款完成度很高的模糊查找，定位是「大概记得名字，立刻打开或拖走」，结果还封顶。那不是摊开所有匹配，不是同一顿饭。

### 先做哪、先不做哪

先做 Mac。Windows 已有 Everything，不必抢。

第一刀先扫个人文件夹里本机已经有的文件。云盘默认不算——占位文件又多又慢，第一次扫描会被拖垮。外置盘要搜，自己在设置里加。排除范围内也可以单独纳入某几个文件夹；微信聊天里传来的文件默认算上。

没开「完全磁盘访问」时，受保护的位置会搜不全。这影响全不全，不妨碍敲第三个字时列表已经变了。

### 明确不做

- 不当启动器
- 不搜正文
- 不走系统那套混合搜索
- 不做 Windows 版
- 不为了快去接系统搜索

### 还没对齐

收费、上架、中文分词和拼音，都还没定，先不写进要做的设计。

## 行为契约

- 打开就能敲。不必先选「按名称搜索」，也不必按回车。
- 空着时也能看见已经扫到的文件；再打字，列表立刻变窄。退格，列表重新变宽。
- 结果是一张表，至少能看见名称和所在路径。
- 界面语言跟系统走，中文叫旗鱼搜索，英文叫 Sailfish Everything。
- 关掉或最小化窗口不是退出。软件收到屏幕右上角，图标还在；点图标或按热键还能唤回来。只有选退出才真正关掉。
